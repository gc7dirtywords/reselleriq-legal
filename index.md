# ResellerIQ Privacy Policy

**Last updated: November 1, 2026**

## Overview

ResellerIQ is a privately operated application designed to manage reseller inventory, analyze sales performance, and track e-commerce business activity.

ResellerIQ integrates with eBay using its official APIs and OAuth authorization system.

## Information Accessed

When authorized through eBay, ResellerIQ may access:

- eBay account identifiers
- Active and historical listings
- Inventory and product information
- Sales, orders, and transaction information
- Pricing, fees, shipping, and related selling data

The specific information accessed depends on the permissions granted during eBay authorization.

## How Information Is Used

Information obtained through eBay is used for inventory management, sales reporting, business analytics, and related reseller operations.

ResellerIQ does not sell eBay account information or use it for advertising.

## Data Storage and Security

ResellerIQ operates on privately managed, self-hosted infrastructure. Access to the application is restricted using authentication and access controls.

OAuth authorization allows ResellerIQ to access permitted eBay data without collecting the user's eBay password.

## Third-Party Services

ResellerIQ communicates with eBay through its official APIs and uses Cloudflare for secure application connectivity and access protection.

This privacy policy is publicly hosted using GitHub Pages.

## Authorization and Data Removal

eBay authorization can be revoked through the user's eBay account settings.

Revoking authorization prevents further authorized API access but does not automatically delete previously retrieved information. Locally stored application data can be deleted by the application owner.

## Changes to This Policy

This policy may be updated to reflect changes in ResellerIQ's functionality or data-handling practices.
